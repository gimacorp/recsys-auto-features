# Автоматический поиск временных признаков для рекомендаций

Исследовательский проект для задания об автоматизации feature engineering в рекомендательных системах.

Цель: сравнить сильный CatBoost с ручными признаками, случайный поиск дополнительных признаков и поиск, направляемый ошибками текущей модели. Все исторические признаки используют события со временем строго меньше времени прогнозируемого события.

Основной датасет — MovieLens 100K. Целевая переменная: `rating >= 4`. Работа исследует предпочтения среди фильмов с наблюдаемыми оценками. Интерпретация результатов учитывает механизм сбора этих оценок.

Протокол и критерии успеха: [docs/protocol.md](docs/protocol.md). Инструкции воспроизведения и итоговые результаты будут добавлены после запуска экспериментов.
