# Проверка готового проекта

## Локальные проверки

- `ruff check src tests`: успешно.
- `ruff format --check src tests`: успешно.
- `pytest -q`: 48 тестов проходят, включая генерацию отчёта с одним fold/seed.
- Все относительные ссылки README и документов ведут к существующим файлам.
- Все три итоговых графика просмотрены: подписи на русском, легенды и интервалы читаются.

## Проверка свежей копии

Репозиторий склонирован с GitHub в отдельный временный каталог. В нём создано новое виртуальное окружение и выполнена установка `pip install -e '.[dev]'`. Датасет скачан заново с проверкой контрольной суммы.

Выполнены короткий основной эксперимент, аудит, поиск с исходными статическими признаками, оценка каталога, абляции и генерация отчёта. Метрики всех шести основных методов короткого эксперимента точно совпали с соответствующим запуском в рабочей папке. Аудит проверил 42 значения метрик, два поисковых бюджета и две временные границы этой конфигурации.

Проверка выявила ограничение первоначального генератора графиков на один seed/fold. Генератор исправлен; добавлен регрессионный тест. Отчёт короткого эксперимента затем сформирован успешно. Итоговый полный отчёт повторно сгенерирован из сохранённых JSON.

## Проверка полного эксперимента

[audit.json](../artifacts/full/audit.json) фиксирует пересчёт 252 основных значений метрик, 12 поисковых бюджетов и четырёх временных границ. [model_export_audit.json](../artifacts/full/model_export_audit.json) фиксирует восстановление 12 автоматически выбранных моделей с точным совпадением сохранённых метрик в том же окружении.

Полный основной эксперимент использует два временных разбиения и три seed. Дополнительный поиск с исходными статическими признаками повторён для всех шести сочетаний fold/seed. Сохранены все 468 проверок предложений: 180 в основном поиске и 288 в дополнительном.
