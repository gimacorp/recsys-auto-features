# Проверка готового проекта

## Локальные проверки

- `ruff check src tests`: успешно.
- `ruff format --check src tests`: успешно.
- `pytest -q`: проверки охватывают исторические признаки, будущие метки, метрики, генерацию отчёта, парный поиск, конфигурации и атомарную запись.
- Все относительные ссылки README и документов ведут к существующим файлам.
- Все три итоговых графика просмотрены: подписи на русском, легенды и интервалы читаются.

## Проверка свежей копии

Репозиторий склонирован с GitHub в отдельный временный каталог. В нём создано новое виртуальное окружение и выполнена установка `pip install -e '.[dev]'`. Датасет скачан заново с проверкой контрольной суммы.

Выполнены короткий основной эксперимент, аудит, поиск с исходными статическими признаками, оценка каталога, абляции и генерация отчёта. Метрики всех шести основных методов короткого эксперимента точно совпали с соответствующим запуском в рабочей папке. Аудит проверил 42 значения метрик, два поисковых бюджета и две временные границы этой конфигурации.

Проверка выявила ограничение первоначального генератора графиков на один seed/fold. Генератор исправлен; добавлен регрессионный тест. Отчёт короткого эксперимента затем сформирован успешно. Итоговый полный отчёт повторно сгенерирован из сохранённых JSON.

## Проверка полного эксперимента

[audit.json](../artifacts/full/audit.json) фиксирует пересчёт 252 основных значений метрик, 12 поисковых бюджетов и четырёх временных границ. [model_export_audit.json](../artifacts/full/model_export_audit.json) фиксирует восстановление 12 автоматически выбранных моделей с точным совпадением сохранённых метрик в том же окружении.

Полный основной эксперимент использует два временных разбиения и три seed. Дополнительный поиск с исходными статическими признаками повторён для всех шести сочетаний fold/seed. Сохранены все 468 проверок предложений: 180 в основном поиске и 288 в дополнительном.

## GitHub и авторство

GitHub Actions выполняет unit-тесты и статические проверки на Python 3.11/3.13, а также end-to-end короткий эксперимент на Linux. [История CI](https://github.com/gimacorp/recsys-auto-features/actions/workflows/checks.yml) позволяет проверить статус конкретного коммита.

Коммиты разработки подписаны именем Karim Gimadiev и GitHub noreply-адресом аккаунта `gimacorp`. GitHub связывает авторство опубликованной истории с этим аккаунтом; пользовательское исправление README через веб-интерфейс сохранено отдельным коммитом. Сообщения коммитов написаны на английском, пояснения и отчёт — на русском. История отражает реальные этапы разработки, проверок и экспериментов.

## Повторная проверка

Реализация исправлена после дополнительного аудита: изоляция артефактов, явные проверки, корректные cutoff-названия, выравнивание строк, защита незавершённых запусков и атомарная запись. Полный список с проверками приведён в [review.md](review.md).

Для каждой когорты MovieLens 1M аудит пересчитывает 126 значений метрик, шесть основных поисковых бюджетов и две временные границы. Новые исследования включают совместный пользовательский bootstrap средних по seed потерь, фиксированные временные stress-группы и два заранее зафиксированных протокола переноса.

Всего сохранено 993 попытки предложений. Новые модели и предсказания исключены из Git и размещены внутри собственных каталогов запусков. `captured_utc` в новых provenance означает момент фиксации метаданных; раннее поле `started_utc` дополнительных модулей обозначало именно этот момент и могло фиксироваться после завершения вычислений.
