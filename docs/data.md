# Данные и семантика целевой переменной

Используется полный MovieLens 100K: 100 000 оценок 943 пользователей для 1 682 фильмов. Исходный архив скачивается с сервера GroupLens по HTTPS и проверяется по SHA-256 `50d2a982c66986937beb9ffb3aa76efe955bf3d5c6b761f4e3a7cd717c6a3229`.

Положительный отклик — оценка 4 или 5. Оценки 1–3 образуют отрицательный класс. Это прогноз удовлетворённости среди наблюдаемых оценок. Протокол опирается на явный feedback; конверсия кликов и показов потребовала бы журналов показов.

Один фильм может иметь несколько жанров. История жанра и пользовательско-жанровая история рассчитываются для каждого жанра отдельно, затем объединяются средним, максимумом или минимумом. Повторные пары user–item в этом датасете отсутствуют, поэтому прямые признаки user–item должны оставаться константными. Этот факт служит дополнительным диагностическим контролем.

Используется глобальное временное разбиение. Оценки пользователей могут поступать пачками; одинаковые timestamp обрабатываются атомарно. Демография и полный набор жанров трактуются как доступные статические метаданные. Полный каталог допускается известным заранее, что отдельно ограничивает интерпретацию cold-start эксперимента.

При последовательной оценке история пополняется фактическими откликами с более ранним timestamp, включая события внутри validation и test. Предполагается мгновенная доступность рейтинга. Такой режим соответствует обновляемому сервису; отложенный feedback требует учёта дополнительного времени доступности метки.

Источники: [GroupLens README и лицензия](https://files.grouplens.org/datasets/movielens/ml-100k-README.txt), [Harper & Konstan, 2015](https://doi.org/10.1145/2827872). Данные исключены из Git и скачиваются пользователем самостоятельно: условия GroupLens предусматривают отдельное разрешение на перераспространение.
