# Дополнительные эксперименты

Эти проверки добавлены после запуска основного протокола. Они служат анализу механизма и ограничений метода. Итоговые выводы учитывают их исследовательский статус и общий тестовый набор.

## Поиск с исходными статическими признаками

Основное сравнение дополняет сильную ручную модель. Отдельный вопрос — насколько близкое качество получится, если предоставить алгоритму только статические признаки и грамматику агрегатов.

Обе стратегии получают все 65 пакетов (20 из ручного baseline и 45 дополнительных), начинают с CatBoost на статических признаках и проводят восемь раундов по три предложения, всего 24 переобучения. Гиперпараметры сохраняются из основного эксперимента; критерий отбора и временные границы остаются теми же. Проверяются все три seed и оба fold. Сравниваются качество, число выбранных пакетов и время обучения с ручной моделью.

Вывод о применимости автоматизации может опираться на сопоставимое качество при меньшем числе выбранных признаков. Утверждение о превосходстве требует дальнейшей проверки на новом датасете. Сущности, набор агрегатов и возможные окна задаются грамматикой; алгоритм автоматизирует выбор внутри этого пространства.

## Ранжирование каталога в фиксированный момент

На начало каждого test фиксируется доступная история. Кандидаты — все фильмы с взаимодействиями до этой границы; фильмы из истории конкретного пользователя исключаются. Ground truth — фильмы с положительными оценками в test, которые входят в доступный каталог. Пользователи с минимум одним таким фильмом входят в оценку, включая пользователей с пустой историей. Метаданные пользователя считаются известными на момент запроса.

Recall@10 и NDCG@10 рассчитываются по полному доступному набору кандидатов. История внутри test остаётся замороженной. Будущие положительные оценки образуют ретроспективный ground truth; остальные фильмы имеют неизвестную реальную полезность и получают нулевую релевантность только в данном протоколе. Эта оценка измеряет извлечение будущих положительных взаимодействий и зависит от селективности наблюдаемых оценок.

Оценка запускается для всех пользователей с доступным ground truth, всех seed и моделей основного эксперимента. Сохраняются размер каталога, покрытие положительных событий, среднее число кандидатов, warm/cold-user сегменты и парные пользовательские bootstrap-интервалы.

## Абляции и обновление feedback

Для первого заранее заданного seed каждого fold поочерёдно удаляется одна семья исторических признаков: user, item, genre, user×genre. Гиперпараметры фиксированы, число деревьев заново выбирается на validation. Это диагностирует вклад семей и допускает взаимодействие с моделью.

Отдельно все наблюдаемые пары test оцениваются на начале периода с замороженной историей. Сравнение с основной последовательной оценкой показывает чувствительность к допущению о немедленном поступлении feedback. В этой проверке время запроса также фиксировано; различие включает обновление истории и изменение временных признаков.
