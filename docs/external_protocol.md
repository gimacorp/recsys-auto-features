# Независимая проверка на MovieLens 1M

Протокол фиксируется до обучения и просмотра метрик MovieLens 1M. Предыдущие результаты MovieLens 100K используются для выбора исследуемого алгоритма; новый набор выступает отложенной проверкой переноса выводов.

## Данные и выборка

Официальный MovieLens 1M содержит 1 000 209 оценок 6040 пользователей. Используется заранее заданная когорта `user_id % 6 == 0`, приблизительно одна шестая пользователей, со всеми её оценками. Отбор определяется идентификатором и сохраняет целые пользовательские истории. Ограничение вычислительного бюджета задаётся до просмотра меток. Представительность такой детерминированной когорты остаётся ограничением.

Каталог и демография приводятся к схеме основного проекта. Age в MovieLens 1M — код возрастного диапазона, occupation — категориальный код. Year извлекается из названия фильма. Жанры сохраняются многозначными. Исторические item/genre агрегаты рассчитываются по выбранной когорте.

## Фиксированные решения

Глобальное train/validation/test = 65%/15%/20%, атомарные timestamp, немедленная доступность прошлых оценок. Seed 17/42/73. Грамматика, ручные окна, дополнительные окна, сглаживание, корреляционный proxy, критерий принятия и budgets сохраняются из первого исследования. Основной поиск: 15 проверок на стратегию/seed. Построение с нуля: 24 проверки на стратегию/seed.

Встроенный one-hot порог повышается до 65535 одинаково для всех моделей нового датасета, чтобы охватить более крупный каталог и сохранить семантику обработки категорий. Шесть конфигураций CatBoost выбираются на новой validation, по той же заранее заданной сетке. Тест остаётся за пределами выбора.

## Проверяемые утверждения

Основное утверждение: направляемое построение с нуля даёт компактный набор с приемлемой потерей log loss относительно ручного baseline. Заранее задаются два практических критерия: среднее число признаков ≤60% ручного набора; верхняя граница парного 95%-bootstrap интервала прироста log loss <0.01. Допуск 0.01 является исследовательским практическим порогом, выбранным до нового эксперимента. Bootstrap оценивает среднюю потерю по трём seed на пользователях нового test; усредняются потери, а не вероятности.

Направляемое и случайное построение также сравниваются напрямую с пользовательскими интервалами. Улучшение ранжирования каталога оценивается отдельно и требует своих результатов. Все сравнения публикуются независимо от знака эффекта; дальнейшее изменение метода потребует новой независимой проверки.

Это перенос на другой датасет той же платформы, с иной эпохой и объёмом истории. Проверка усиливает вывод об устойчивости алгоритма в MovieLens; перенос на другую предметную область требует отдельного исследования.

Источник и условия использования: [официальный README MovieLens 1M](https://files.grouplens.org/datasets/movielens/ml-1m-README.txt). Исходные файлы исключены из Git.
